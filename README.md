# Iris Data Visualization

## Project Overview
This project explores the Iris dataset through data visualization techniques to understand patterns and relationships among flower measurements.

## Objectives
- Understand the structure of the Iris dataset.
- Explore sepal and petal measurements.
- Compare measurements across Iris species.
- Create visualizations to communicate patterns in the data.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Load and inspect the dataset.
2. Examine the available columns and species.
3. Create visualizations of flower measurements.
4. Compare patterns across species.
5. Summarize the observations.

## Files
- `iris_data_visualization.ipynb` — notebook containing code, explanations, visualizations, and outputs.

## How to Run
Open the notebook in Google Colab and run the cells from top to bottom.

## Dataset
The Iris dataset is available through [scikit-learn documentation](https://scikit-learn.org/stable/auto_examples/datasets/plot_iris_dataset.html).
